## বাংলা ব্রাউজার ১.০

প্রথম ভার্সন। ছোট, দ্রুত, পুরোটাই বাংলায়।

**ফিচার**

- উপরে ঠিকানা বার। সাইটের নাম লিখলে সাইট খোলে, বাংলা শব্দ লিখলে গুগলে সার্চ হয়
- নিচে পাঁচটি বাটন: পিছনে, সামনে, হোম, বুকমার্ক, মেনু
- বুকমার্ক আর ইতিহাস সেভ থাকে
- রাতের মোড, ডেস্কটপ সাইট মোড
- ফাইল ডাউনলোড ও আপলোড
- কুকি সেভ থাকে, তাই সাইটে লগইন থাকে
- হোম পেজে প্রথম আলো, বিডিনিউজ, উইকিপিডিয়া, ইউটিউব, ফেসবুকের শর্টকাট
- সাইজ মাত্র ৪৯ কিলোবাইট

**ইনস্টল**

APK ফোনে নামিয়ে ফাইল ম্যানেজার দিয়ে ট্যাপ করো। "Allow from this source" চালু করে Install চাপো। অ্যাপটি নিজের বানানো কী দিয়ে সাইন করা, তাই Android অচেনা সোর্সের সতর্কতা দেখাবে।

**জানা সীমাবদ্ধতা**

- Google WebView-এর ভিতরে লগইন আটকে রাখে। জিমেইল বা ইউটিউব লগইন লাগলে মেনু থেকে "অন্য ব্রাউজারে খুলুন" চেপে ক্রোমে খোলো
- Netflix, Prime Video-র DRM ভিডিও চলবে না
- কিছু সাইট WebView-এ লোড হতে না-ও পারে

---

First release. A 49 KB Android browser with a Bengali interface.

Install the APK, allow the unknown source when Android asks, and tap install. Google blocks sign-in inside WebView, so use "Open in another browser" for Gmail or YouTube logins.
