## বাংলা ব্রাউজার ১.১

**নতুন কী এসেছে**

- **ট্যাব** — Chrome-এর মতো একসাথে ৮টা পর্যন্ত ট্যাব। উপরে ডান দিকে সংখ্যাটা দেখায় কতটা ট্যাব খোলা, চাপ দিলে সব ট্যাবের তালিকা আসে, ✕ দিয়ে বন্ধ করা যায়।
- **নতুন মেনু** — Edge ব্রাউজারের মতো নিচ থেকে উঠে আসা মেনু। নতুন ট্যাব, বুকমার্ক, ইতিহাস, ডাউনলোড, শেয়ার, ডেস্কটপ সাইট, রাতের মোড সব এক জায়গায়।
- **সেটিংস স্ক্রিন** — সার্চ ইঞ্জিন বদলানো (Google, DuckDuckGo, Bing), লেখার আকার ছোট-বড় করা, জাভাস্ক্রিপ্ট আর ছবি লোড বন্ধ-চালু করা।
- **ডেটা মোছা** — এক ট্যাপে ইতিহাস, বুকমার্ক, কুকি ও ক্যাশে মুছে ফেলা।
- **সেশন সেভ** — অ্যাপ বন্ধ করে আবার খুললে আগের ট্যাবগুলো ফিরে আসে।

**আপডেট করতে**

পুরোনো অ্যাপটা মুছতে হবে না। নতুন APK ট্যাপ করে Install চাপলেই পুরোনোটার উপর বসে যাবে, বুকমার্ক আর ইতিহাস থাকবে।
