License 2.0. That license covers code only. It does not give anyone the right
to use the project's name or icon.

These belong to the project owner (Mamun):

- The name **বাংলা ব্রাউজার** and **Bangla Browser**
- The app icon in `res/mipmap-*` and `docs/icon.png`
- The GitHub organisation and repository at `github.com/mamun0937/bangla-browser`
- The published APK, its signing key, and the package id `bd.bangla.browser`

## If you fork

The MPL lets you copy, change and share the code. It does not let you ship
your build under the project's name or icon. If you publish a modified
version, you must:

1. Pick a different app name.
2. Use a different app icon.
3. Use your own package id, your own signing key, and your own listing.
4. Make clear that your build is unofficial and not supported here.

Nominative use is fine. You may write "based on Bangla Browser" in your
description or credits.

## Official builds

Only APKs published at
<https://github.com/mamun0937/bangla-browser/releases> are official.
